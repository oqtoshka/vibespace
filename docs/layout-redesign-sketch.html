Session pane — chat ⇄ terminal switch, remembered per session. Files pane — the only place tabs live. ✕ on session head — collapses the session pane (files-only). Divider — drag to resize (persisted).

What changes vs. today

• Tabs become files-only. useWorkspaceTabs stops holding chat/shell tabs; the tab strip renders file tabs only.
• New per-session view state { [sessionId]: 'chat' | 'terminal' } drives the session-pane switch (persisted per project).
• Two panes with a draggable, persisted divider. Files-pane collapses to 0 when no files are open (session full width); session-pane has a close button (files-only).
• One terminal per session (default assumption) — bound to the session's cwd/worktree, lazily started on first reveal. (Say the word if you want multiple shells per session instead.)
• Mobile = single column with a Session/Files top switch (default assumption).
